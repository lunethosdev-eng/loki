# Loki / Pokke

New repo project based on BitChord UI, player, lyrics, connectors, Liquid Glass.

## Branding
- App name: **Pokke**
- applicationId: `com.music.pokke`
- Repo intended: **loki**

## Settings to KEEP
- Listen Together / party server
- Crossfade / skip silence
- Audio quality (Wi‑Fi / cellular)
- Equalizer
- Liquid Glass / reduce animations / blur
- Lyrics (sources, blur, sync)
- Canvas / artwork
- Theme light/dark
- Music sources (Ukiyo when wired)
- Account / profile (Kokoro)
- Spotify connector
